SANDLINE — a 5v5 round-based tactical FPS in three.js: plant/defuse on the SANDLINE YARD map, a buy economy with 8 items, four weapons plus smoke and flash, headshots, and bots that fight, plant, and defuse. Single-player against bots, from static files with no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
